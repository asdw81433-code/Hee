# Kivo — เพื่อนหุ่นยนต์บนหน้าจอ (Android, AI ในเครื่องทั้งหมด)

Kivo เป็นหุ่นยนต์ 3D ตัวจิ๋วที่ลอยอยู่บนจอมือถือ คุยได้ จำเรื่องของเราได้ มีอารมณ์จำลอง ชวนเล่นเกมเอง
มองหน้าจอและกดแทนเราได้เมื่ออนุญาต **AI ทุกส่วนทำงานในเครื่อง ไม่ใช้ Claude / OpenAI / Gemini หรือ AI บนคลาวด์ใดๆ ไม่มี API key**

- เป้าหมาย: Samsung Galaxy A07 4G (Android 16, RAM 4 GB, Helio G99) · `minSdk 26` · `targetSdk 36` · arm64
- Package ID: `com.livingai.companion` (คงเดิม ติดตั้งทับของเก่าได้ ข้อมูลเดิมถูกนำเข้า)
- เวอร์ชัน 1.0.0 · APK ประมาณ 17.5 MB (ยังไม่รวมโมเดลภาษา ซึ่งเลือกดาวน์โหลดเองทีหลัง)

เอกสาร: [สถาปัตยกรรม](docs/ARCHITECTURE.md) · [การติดตั้งโมเดล](docs/MODELS.md) · [ผลทดสอบจริง](docs/TEST_RESULTS.md) · [ข้อจำกัด](docs/LIMITATIONS.md)

## ติดตั้ง

1. ดาวน์โหลด `kivo-1.0.0.apk` จากหน้า Releases ของ repo (tag `living-ai-latest`) แล้วแตะเพื่อติดตั้ง
2. เปิดแอป กด **"แสดง Kivo บนจอ"** แล้วอนุญาต "แสดงทับแอปอื่น" → หุ่นจะลอยบนทุกแอป
3. (ไม่บังคับ) เปิดสิทธิ์อื่นเมื่ออยากใช้: การช่วยเหลือพิเศษ = ให้กดแทน, แชร์หน้าจอ = ให้เห็นภาพเกม/วิดีโอ, ไมค์ = สั่งด้วยเสียง
4. (ไม่บังคับ) กด **🤖 สมอง AI** เพื่อดาวน์โหลดโมเดลภาษา ถ้าไม่โหลด Kivo ยังคุยพื้นฐาน เล่นเกม และทำตามคำสั่งได้ครบ

ถ้า Samsung ขึ้น "แอปถูกปฏิเสธไม่ให้เข้าถึง" ตอนเปิดการช่วยเหลือพิเศษ: ข้อมูลแอป → ⋮ → "อนุญาตการตั้งค่าที่ถูกจำกัด"
(เป็นกลไกความปลอดภัยของ Android สำหรับแอปนอก Play Store แอปข้ามให้ไม่ได้และไม่พยายามข้าม)

## ความปลอดภัยและความเป็นส่วนตัว

- ใช้เฉพาะสิทธิ์ที่ผู้ใช้เปิดเอง ไม่ข้ามระบบความปลอดภัยของ Android, หน้าจอที่แอปป้องกัน (FLAG_SECURE) เห็นเป็นภาพดำและไม่เลี่ยง
- ไม่อ่านช่องรหัสผ่าน ไม่แตะหน้าที่มี PIN/OTP/รหัสผ่าน, OTP และเลขบัตรถูกปิดบังก่อนบันทึก
- ส่ง / ซื้อ / จ่าย / โอน / ลบ ต้องยืนยันทุกครั้ง, ข้อความที่ร่างให้ผู้ใช้กดส่งเอง
- โมเดลภาษา **คุยอย่างเดียว** ไม่มีสิทธิ์สั่งการกระทำ การกระทำมาจากตัวแปลคำสั่งแบบกฎที่ผ่านนโยบายความปลอดภัย
- หยุดทันที: แตะหุ่นขณะทำงาน ปุ่มหยุดในแอป หรือปุ่มในแถบแจ้งเตือน
- ข้อมูลอยู่ในเครื่อง ไม่สำรองขึ้นคลาวด์ ลบทั้งหมดได้ในตั้งค่า, ไมค์เปิดเฉพาะตอนกด 🎤, เน็ตใช้เฉพาะตอนผู้ใช้กดดาวน์โหลดโมเดล

## Build

ต้องมี JDK 17, Android SDK (API 36), NDK 27.3.13750724, CMake 3.31.5 และอินเทอร์เน็ต (Google Maven, Maven Central, JitPack, GitHub สำหรับ llama.cpp)

```bash
cd living-ai
./gradlew :core:test                       # เทสต์แกน (JVM)
./gradlew :app:assembleRelease             # APK: app/build/outputs/apk/release/app-release.apk
./gradlew :app:connectedDebugAndroidTest   # เทสต์บนเครื่อง/อีมูเลเตอร์
```

เทสต์เอนจิน AI บน PC (ไม่ต้องมีมือถือ):

```bash
git clone --depth 1 --branch b6500 https://github.com/ggml-org/llama.cpp.git /tmp/llama.cpp
cmake -S app/src/main/cpp -B /tmp/kivo-native -DLLAMA_DIR=/tmp/llama.cpp && cmake --build /tmp/kivo-native -j --target kivo_llama
pip install numpy && python3 scripts/make_tiny_gguf.py /tmp/llama.cpp /tmp/tiny.gguf
./gradlew :core:test -PllamaLib=/tmp/kivo-native/libkivo_llama.so -PtinyModel=/tmp/tiny.gguf [-PrealModel=/path/model.gguf]
```

เครื่องที่เข้า Google Maven ไม่ได้: `./gradlew :core:test :typecheck:compileKotlin -PcoreOnly=true`
CI (`.github/workflows/living-ai-android.yml`) ทำทั้งหมดนี้ทุก push และเผยแพร่ APK
