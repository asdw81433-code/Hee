# ข้อจำกัดที่ทราบ

## ยังไม่ได้ทดสอบบนเครื่องจริง
ทุกอย่างทดสอบบนอีมูเลเตอร์ Android 16 (x86_64) และบน PC ใน CI เท่านั้น **ยังไม่มีการรันบน Galaxy A07 จริง** ดังนั้นยังไม่ทราบ:
ความเร็วโมเดล (โทเคน/วินาที), RAM ที่ใช้จริง, FPS ของหุ่น, การกินแบต, พฤติกรรมของ One UI ต่อบริการเบื้องหน้า
ตัวเลขเหล่านี้วัดได้ในแอป (ตั้งค่า → ประสิทธิภาพ, สมอง AI → ทดสอบความเร็ว)

## สมอง AI
- โมเดล 0.5–1.7B ตอบข้อเท็จจริงผิดบ่อย (ในเทสต์ถาม "1 สัปดาห์มีกี่วัน" มีรุ่นที่ตอบผิด) ภาษาไทยมีประโยคแปลกเป็นระยะ
- โมเดลไม่เห็นภาพ: รูปที่แนบถูกอ่านเฉพาะตัวหนังสือด้วย OCR
- โมเดลไม่สั่งการกระทำ: คำสั่งต้องตรงรูปแบบที่ตัวแปลคำสั่งรู้จัก (พิมพ์ `คำสั่ง` เพื่อดู)
- รองรับ 64-bit เท่านั้น (arm64-v8a)

## เสียง
- ไม่มีโมเดล STT/TTS ของตัวเอง ใช้ของระบบ การฟัง/พูดไทยแบบออฟไลน์ขึ้นกับว่าเครื่องมีชุดภาษาไทยออฟไลน์หรือไม่ ถ้าไม่มี การฟังจะต้องใช้เน็ต (ผ่านบริการจดจำเสียงของเครื่อง ไม่ใช่ของแอป)
- ไม่มีคำปลุก (wake word): ต้องกด 🎤

## Android
- แอปเปิด/ปิด Wi-Fi บลูทูธ ฯลฯ เองไม่ได้ (Android ห้าม) จึงเปิดหน้าตั้งค่าให้ผู้ใช้กดเอง
- แอปที่ติดตั้งนอก Play Store ต้อง "อนุญาตการตั้งค่าที่ถูกจำกัด" เองก่อนเปิดการช่วยเหลือพิเศษ
- แชร์หน้าจอต้องกดยอมรับทุกครั้ง และระบบหยุดให้เมื่อล็อกจอ
- การเตือนอาจช้าไม่กี่นาทีถ้าไม่เปิดสิทธิ์ "การปลุกและการช่วยเตือน", ระบบประหยัดแบตของผู้ผลิตอาจปิดบริการ (ตั้งแอปเป็น "ไม่จำกัด" ช่วยได้)
- OCR ทั้งหน้าจอใช้เวลาหลักวินาที และอ่านฟอนต์ลวดลาย/ตัวเล็กมากได้ไม่ดี

## ตัวละคร
- ปรับรูปลักษณ์ได้เฉพาะชุดสี 6 แบบ (ยังไม่มีเครื่องประดับ/รูปทรงอื่น)
- หุ่นเรนเดอร์ด้วย Canvas (ซอฟต์แวร์ 3D) ไม่ใช่โมเดล GPU
- เกมบนจอที่ไม่มี UI (วาดเอง) Kivo เล่นแทนไม่ได้ ทำได้แค่อ่านข้อความด้วย OCR
