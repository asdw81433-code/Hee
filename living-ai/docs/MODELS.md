# โมเดลภาษา: ติดตั้ง เลือก และถอด

Kivo ใช้โมเดลรูปแบบ **GGUF** รันด้วย **llama.cpp** (tag `b6500`) ในเครื่อง ไม่มีการส่งข้อความออกนอกเครื่อง
โมเดลไม่ได้มากับ APK และ **จะไม่ถูกดาวน์โหลดหรือโหลดเข้า RAM จนกว่าผู้ใช้จะสั่ง**

## ติดตั้งจากในแอป

หน้าแรก → **🤖 สมอง AI** → เลือกโมเดล → **ดาวน์โหลด** → อ่านขนาด / ที่มา / สัญญาอนุญาต → **ยอมรับและดาวน์โหลด**

- โหลดต่อจากที่ค้างได้ถ้าเน็ตหลุด, เตือนเมื่อใช้เน็ตมือถือ, ตรวจพื้นที่ว่างก่อน
- โหลดเสร็จตรวจ SHA-256 กับค่าที่ฝังในแอป ถ้าไม่ตรงไฟล์ถูกลบ
- เก็บใน `files/models/` ของแอป (พื้นที่ส่วนตัว) ลบได้จากหน้าเดียวกัน

| โมเดล | ขนาด | สัญญาอนุญาต | SHA-256 | หมายเหตุจากการทดสอบจริง |
|---|---|---|---|---|
| Gemma 3 1B it Q4_K_M (แนะนำ) | 806 MB | Gemma Terms of Use | `8ccc5cd1…eb75a135` | ภาษาไทยเป็นธรรมชาติที่สุด อยู่ในบทบาท ใช้ความจำได้ ความรู้ทั่วไปผิดบ่อย |
| Qwen3 1.7B Q4_K_M | 1,107 MB | Apache-2.0 | `b139949c…fa181897` | ช้ากว่าราวครึ่ง ตอบตรงคำถามกว่าเล็กน้อย |
| Qwen2.5 0.5B Instruct Q4_K_M | 491 MB | Apache-2.0 | `74a4da8c…93d7a9db` | เล็กและเร็วสุด ภาษาไทยอ่อน |

ที่มา: `huggingface.co/ggml-org/gemma-3-1b-it-GGUF`, `huggingface.co/unsloth/Qwen3-1.7B-GGUF`, `huggingface.co/Qwen/Qwen2.5-0.5B-Instruct-GGUF`
(ค่า SHA-256 เต็มอยู่ใน `core/.../ai/Models.kt`)

## ติดตั้งแบบออฟไลน์ / ใช้โมเดลของตัวเอง

1. ดาวน์โหลดไฟล์ `.gguf` ด้วยคอมหรือเครื่องอื่น แล้วโอนเข้ามือถือ
2. หน้า **สมอง AI** → **นำเข้าไฟล์ .gguf** → เลือกไฟล์

รับเฉพาะไฟล์ที่ขึ้นต้นด้วยลายเซ็น GGUF ใช้ได้กับโมเดลแชตที่ llama.cpp รองรับและมี chat template ในไฟล์
(ถ้าไม่มีจะใช้รูปแบบ ChatML) แนะนำขนาดไม่เกิน ~1.2 GB สำหรับเครื่อง RAM 4 GB ไฟล์ที่นำเข้าเองไม่มีการตรวจ checksum

## การใช้ RAM และความเร็ว

- โหลดเมื่อมีข้อความที่ต้องใช้โมเดล (หรืออุ่นเครื่องเมื่อเริ่มพิมพ์ในแชต) ใช้ mmap
- ถอดเองเมื่อไม่ได้ใช้ ~5 นาที, เมื่อระบบแจ้ง RAM ต่ำ, หรือกด "ถอดโมเดลออกจาก RAM"
- ถ้า RAM ไม่พอ (ต้องเหลือเผื่อระบบ 300 MB) จะไม่โหลดและบอกเหตุผล แทนที่จะเสี่ยงให้แอปถูกปิด
- บริบท 2048 โทเคน (1024 ในโหมด RAM ต่ำ), ส่วนต้นของพรอมต์ถูกแคช จึงอ่านเฉพาะข้อความใหม่
- **ทดสอบความเร็ว** ในหน้าเดียวกัน วัดจริงบนเครื่องด้วย 2/4/6 เธรดแล้วเลือกที่เร็วสุด

โมเดลในเครื่องช้ากว่าและฉลาดน้อยกว่า AI บนคลาวด์มาก และตอบผิดได้ อย่าใช้เป็นแหล่งข้อเท็จจริง
