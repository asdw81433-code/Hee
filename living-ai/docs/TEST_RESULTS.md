# ผลทดสอบจริง

ทุกอย่างในหน้านี้มาจากการรันจริงใน GitHub Actions (`.github/workflows/living-ai-android.yml`)
ไม่มีรายการใดที่อ้างโดยไม่ได้รัน สิ่งที่ **ยังไม่ได้ทดสอบ** ระบุไว้ท้ายหน้า

สภาพแวดล้อม: runner Ubuntu 4 คอร์ (x86_64) · อีมูเลเตอร์ Android 16 (API 36, google_apis, x86_64, RAM 4 GB)
**ไม่ใช่เครื่อง Galaxy A07 จริง** ตัวเลขความเร็วบนมือถือจะต่ำกว่านี้

## 1. เทสต์แกน (JVM) — 79 ข้อ ผ่านทั้งหมด

ครอบคลุม: ตัวแปลคำสั่งและนโยบายความปลอดภัย, การปิดบังข้อมูลลับ, ตัวจัดการทรัพยากร, เรนเดอร์หุ่น (สร้างภาพทุกท่า),
ความจำและการค้นภาษาไทย, การสกัดข้อเท็จจริง, เครื่องสถานะอารมณ์, นิสัย/ความสนิท, ตัวแปลเวลาแบบไทย, เตือนความจำ/โน้ต/to-do,
เกมทั้งหมด (เช่น เอ็กซ์โอ: Kivo ที่เล่นสมบูรณ์ไม่แพ้ใน 40 เกมสุ่ม), นโยบายริเริ่ม (โหมดเงียบ, ห้ามรบกวน, ถอยเมื่อถูกเมิน, เพดานต่อวัน),
ท่อแชต (พรอมต์คงที่เพื่อแคช), ตัวดาวน์โหลด (redirect, ต่อจากที่ค้าง, checksum ผิดแล้วลบ), การนำเข้า GGUF

เอนจิน llama.cpp จริง (ไลบรารี native ที่ build บน runner) กับโมเดลสุ่มขนาดจิ๋ว:
โหลด/ถอด, ข้อความไทย+อีโมจิไม่แตกกลางตัวอักษรทั้งในสตรีม, ใช้แคชซ้ำ, grammar บังคับรูปแบบ, grammar กันภาษาอื่น,
stop string, ยกเลิกกลางทางแล้วใช้ต่อได้, ตัดประวัติเมื่อยาวเกินบริบท

## 2. เทสต์บนอีมูเลเตอร์ Android 16 — 10 ข้อ ผ่านทั้งหมด

| เทสต์ | สิ่งที่พิสูจน์ |
|---|---|
| a_vision_readsRealUiElementsOfAnotherApp | อ่าน UI ของแอปการตั้งค่าได้จริง |
| b_vision_capturesDownscaledScreenshot | จับภาพหน้าจอและย่อขนาด |
| c_action_scrollTapBackHome | เลื่อน แตะ ย้อนกลับ โฮม ทำจริงและตรวจผล |
| d_action_refusesTargetsThatAreNotOnScreen | ไม่กดสิ่งที่ไม่มีบนจอ |
| e_emergencyStop_blocksLookingAndActing | ปุ่มหยุดฉุกเฉินปิดทั้งการมองและการกระทำ |
| f_memory_storeWorks | SQLite: บันทึก แทนที่ ค้นภาษาไทย แก้ ลบ ล้าง |
| g_ocr_readsThaiAndEnglishOnDevice | OCR อ่าน "LIVING AI 2026" และ "สวัสดีครับ ยินดีต้อนรับ" จากภาพ |
| h_orb_floatsOnScreenWithoutAccessibility | หุ่นลอยทับแอปอื่น, ย่อ/คืน, บริการเบื้องหน้าทำงาน, ปิด-เปิดซ้ำ |
| i_screens_openWithoutCrashing | หน้าแรก ตั้งค่า ตัวละคร ความจำ เปิดได้และแสดงข้อมูลจริง |
| j_localModel_loadsAndGeneratesOnDevice | ไลบรารี AI โหลดบน Android, นำเข้า GGUF, สร้างข้อความไทย, ข้อความแชตวิ่งผ่านโมเดล, ถอดเมื่อ RAM ต่ำ |

(j ใช้โมเดลสุ่มขนาดจิ๋ว จึงพิสูจน์กลไก ไม่ใช่คุณภาพคำตอบ)

## 3. โมเดลจริง ผ่านท่อแชตของ Kivo (บน runner 4 คอร์)

คำถามเดียวกัน 9 ข้อ ต่อเนื่องเป็นบทสนทนาเดียว บริบท: ผู้ใช้ชื่อ "ต้น", ความจำ "อาหารที่ชอบ = ส้มตำ"
(รอบนี้ system prompt ยังเป็นภาษาไทย รุ่น 1.0.0 เปลี่ยนเป็นอังกฤษแบบสั้นเพื่อลดโทเคน ผลรอบใหม่อยู่ในล็อก CI ล่าสุด)

| โมเดล | เร็ว (โทเคน/วิ) | ตอบไทย | อักษรจีนปน | ตัวอย่างคำตอบจริง |
|---|---|---|---|---|
| Gemma 3 1B Q4_K_M | ~29 | 9/9 | 0 | "ฉันคือ Kivo หุ่นยนต์ตัวจิ๋ว ที่อยู่บนมือถือต้น … คุณชื่อต้นสินะ?" · "ส้มตำ? สุดยอดเลย!" · ผิด: "1 สัปดาห์มีกี่วัน" → "สิบสัปดาห์…" |
| Qwen3 1.7B Q4_K_M | ~17 | 9/9 | 0 | "เมืองหลวงของไทยคือ กรุงเทพฯ 😊" · "เป็นคนที่ชอบส้มตำเลยนะ!" · ผิด: "1 สัปดาห์มี 7 กิโลเมตร" |
| Qwen2.5 0.5B Q4_K_M | ~52 | 9/9 | 0 | "ประเทศไทยมีเมืองหลวงชื่อกรุงเทพฯ" · หลายข้อวกวนไม่ตรงคำถาม |
| Qwen2.5 1.5B Q4_K_M (ไม่ได้ใส่ในแอป) | ~27 | 9/9 | 0 | "1 สัปดาห์มี 7 วัน" ถูก แต่ภาษาแข็งและหลุดบทบาท |
| Qwen3 0.6B Q4_K_M (ไม่ได้ใส่ในแอป) | ~36 | 7/9 | 0 | ตอบไม่ตรงคำถามเกือบทุกข้อ |

ข้อสังเกตที่วัดได้:
- ก่อนใส่ grammar กันภาษาอื่น Qwen2.5 0.5B หลุดเป็นภาษาจีนกลางประโยค หลังใส่ = 0 ครั้งในทุกโมเดล
- การใช้แคช: ในบทสนทนาต่อเนื่อง โทเคนพรอมต์ 90%+ ถูกใช้ซ้ำ (เช่น prompt=1274 cached=1179)
- ลองใช้โมเดลจำแนกเจตนา (JSON ด้วย grammar) กับ Qwen2.5 0.5B: ถูก 2 ใน 4 → จึง **ไม่** ให้โมเดลสั่งการกระทำ

สรุปตรงๆ: คุยเล่นเป็นเพื่อนได้ (Gemma ดีสุด) แต่ไม่มีรุ่นไหนเชื่อถือได้เรื่องข้อเท็จจริง

## 4. Build

`assembleDebug` + `assembleRelease` ผ่าน รวม native (llama.cpp ผ่าน NDK 27 / CMake) · release APK ≈ 17.5 MB
(libkivo_llama 4.0 MB, Tesseract+Leptonica 6.9 MB, ข้อมูลภาษา OCR 5.2 MB)

## 5. สถานะตามเกณฑ์รับงาน

| เกณฑ์ | สถานะ | หลักฐาน |
|---|---|---|
| แชตออฟไลน์ | ผ่านบนอีมูเลเตอร์ (กลไก) + บน PC (โมเดลจริง) | j, หัวข้อ 3 — ไม่มีการเรียกเครือข่ายในเส้นทางแชต |
| คุยหลายรอบ | ผ่าน | หัวข้อ 3 (9 รอบ, แคชต่อเนื่อง) |
| จำแล้วเรียกคืน | ผ่าน | เทสต์แกน + f; โมเดลจริงใช้ความจำ "ส้มตำ" ในคำตอบ |
| อารมณ์ตามบทสนทนา | ผ่าน (เทสต์แกน) | MindTest, ActivitiesTest |
| หุ่นชวนทำกิจกรรมเอง | ผ่าน (ตรรกะในเทสต์แกน) | InitiativeTest — ยังไม่ได้สังเกตบนเครื่องจริงตามเวลาจริง |
| เปิดแอปด้วยเสียง | **ยังไม่ได้ทดสอบ** | การเปิดแอปจากข้อความผ่านเทสต์; การฟังเสียงต้องใช้ไมค์และบริการจดจำเสียงของเครื่องจริง |
| อ่านจอเมื่ออนุญาต | ผ่าน | a, b, g |
| overlay ทับแอปอื่น | ผ่าน | h |
| ใช้งานต่อเนื่องไม่แครช | บางส่วน | ชุดเทสต์ ~6 นาทีไม่แครช; ยังไม่มีการทดสอบใช้งานยาวหลายชั่วโมง |
| RAM / FPS | **ยังไม่ได้วัดบนเครื่องจริง** | มีตัววัดในแอป (ตั้งค่า → ประสิทธิภาพ) |
| หยุดบริการ + ลบข้อมูล | บางส่วน | ปิด/เปิดหุ่นและล้างความจำผ่านเทสต์ (h, f); ปุ่ม "ลบข้อมูลทั้งหมด" ยังไม่มีเทสต์อัตโนมัติ |

## 6. ยังไม่ได้ทดสอบ

- ทุกอย่างบน Galaxy A07 จริง (ความเร็วโมเดล, RAM, FPS, แบต, One UI)
- เสียง: TTS และการฟังเสียงไทย (อีมูเลเตอร์ CI ไม่มีเสียง)
- การดาวน์โหลดโมเดลจากในแอปบนมือถือ (ตัวดาวน์โหลดทดสอบกับเซิร์ฟเวอร์จำลอง; URL และ checksum ชุดเดียวกันถูกใช้ดาวน์โหลดจริงใน CI ด้วย curl)
- เตือนความจำเมื่อถึงเวลาจริง, การกลับมาหลังรีบูต, ทักเมื่อปลดล็อก, เต้นตามเพลง
- ตั้งปลุก/จับเวลา/หน้าตั้งค่า บนแอปนาฬิกาและการตั้งค่าของ Samsung
- หน้า "สมอง AI", การแนบรูป, ปุ่มลบข้อมูลทั้งหมด (คอมไพล์และ lint ผ่าน แต่ไม่มีเทสต์อัตโนมัติ)
