# NEON BAY: Static Saints

> **ใหม่:** [สังเวียนเลือด: CAGE BLOOD](CageBlood/README.md) — เกม MMA แซนด์บ็อกซ์บนเว็บ (เปิด `CageBlood/index.html` เล่นได้ทันที) ตัวละครเหลี่ยม วาดหน้าเองได้ ระบบเลือด/บาดเจ็บสมจริง โหมดอาชีพพร้อมเนื้อเรื่อง


เกม Open World แนวไซเบอร์พังค์ มุมมองบุคคลที่ 1 สร้างด้วย Unity
ฉากคือ **Neon Bay รัฐฟลอริดา สหรัฐอเมริกา ปี 2089** เป็นเมืองยักษ์ที่สร้างทับไมอามีเก่าซึ่งจมทะเลไปแล้ว มีกำแพงกั้นทะเล (Megawall) สูง 85 เมตรล้อมรอบ

> ทุกอย่างในเกมสร้างด้วยโค้ดตอนเริ่มเกม ทั้งเมือง ตึก texture ป้ายไฟนีออน ตัวละคร รถ เสียงปืน เสียงฝน และเพลง จึงเปิดเล่นได้เลยโดยไม่ต้องหา asset มาใส่

## วิธีเปิดเล่น

**แบบที่ 1 (แนะนำ)**
1. ติดตั้ง **Unity 6** (6000.0 LTS ขึ้นไป) ผ่าน Unity Hub
2. Unity Hub → New project → เลือก template **Universal 3D (URP)**
3. ก๊อปโฟลเดอร์ `Assets/NeonBay` จาก repo นี้ไปวางในโฟลเดอร์ `Assets` ของโปรเจกต์ใหม่
4. เปิด Unity แล้วกด **Play** ได้ทันทีใน SampleScene หรือใช้เมนู **Neon Bay → Play**

**แบบที่ 2**
- Unity Hub → Add project from disk → เลือกโฟลเดอร์ repo นี้
- ตอนเปิดครั้งแรก สคริปต์ Setup จะทำงานเอง: สร้าง scene `NeonBay`, ตั้งค่า Linear color space และสร้าง URP asset พร้อม HDR, เงานุ่ม และ post-processing
- ถ้ามีอะไรไม่ขึ้น ให้กดเมนู **Neon Bay → Setup Project** แล้วตามด้วย **Neon Bay → Play**

> ตอนกด Play ครั้งแรกจะมีหน้า Loading ราว 10-30 วินาที ระหว่างนั้นเกมจะสร้างเมืองทั้งเมือง

## มีอะไรในเกม

**เมือง**
- แผนที่ขนาดประมาณ 2 x 2 กม. แบ่งเป็น 5 ย่าน
  - **Helix Heights**: ตึกระฟ้ากระจก
  - **Neon Strip**: ย่านไนต์ไลฟ์ ป้ายนีออนเต็มถนน มีตลาดกลางคืน
  - **Lowtown**: สลัม
  - **Port Marrow**: ท่าเรือ ตู้คอนเทนเนอร์ และเครน
  - **The Scar**: เขตซากปรักหักพัง
- ป้ายไฟนีออนแบบอเมริกัน (HOTEL, DINER, MOTEL, PAWN, BAIL BONDS ฯลฯ) และป้ายตัวอักษรเรียงแนวตั้ง
- รถไฟฟ้าโมโนเรลวิ่งจริง, รถบินเหนือตึก, ตึกไกล ๆ นอกกำแพงเมือง
- กลางวัน/กลางคืนต่อเนื่อง และสภาพอากาศ 6 แบบ: แจ่มใส, ครึ้ม, หมอกควัน, ฝน, พายุฟ้าผ่า, หมอกพิษ (acid haze)
- พื้นถนนเปียกและสะท้อนแสงตอนฝนตก, มีแสงไฟถนนแบบ volumetric, ไอน้ำ และถังไฟ

**ระบบ**
- **สร้างตัวละคร**
  - เลือกชื่อ, ภูมิหลัง 3 แบบ (Gutter Kid / Corp Washout / Badlands Runner) และความยาก 4 ระดับ
  - แจกแต้ม 5 ค่าสถานะ: BODY, REFLEX, TECH, NEURAL, COOL
  - แต่งหน้าตา และหมุนดูตัวละครแบบ 3D ได้
- **RPG**
  - เลเวล, perk 25 อัน, cyberware 13 ชิ้น (ใส่ได้ 7 ช่อง)
  - Street Cred เพิ่มแล้วได้ส่วนลดและปลดล็อกของดีกว่า
- **การต่อสู้**
  - อาวุธ 10 แบบ ระดับความหายาก 5 ขั้น และอัปเกรดได้ +5
  - มี headshot, critical, recoil, การเล็ง (ADS) และกล้องสไนเปอร์
  - ต่อสู้มือเปล่า, บล็อก, ดาบ Mono-Katana ที่ทำให้เลือดออก
  - ระเบิด frag และ EMP
- **แฮ็ก**: quickhack 7 แบบ, แฮ็ก ATM, ตู้กดน้ำ, เทอร์มินัล และรถ
- **AI**
  - มองเห็นและได้ยินเสียง, หาที่กำบัง, ปาระเบิด, หนีเมื่อกลัว
  - แก๊งยิงกันเอง, netrunner ฝ่ายศัตรูแฮ็กกลับใส่ผู้เล่น, โดรน
  - ตายแล้วล้มแบบ ragdoll
- **ลอบเร้น**: มีมาตรวัดว่าศัตรูสังเกตเห็นหรือยัง, ลอบสังหารจากด้านหลังได้, ย่อตัวแล้วหาตัวยากขึ้น
- **ตำรวจ NBPD**: ค่าความเดือด (heat) 5 ดาว ส่งตำรวจ หน่วยหนัก และโดรนมาไล่ ต้องหลบสายตาจึงจะหลุด
- **รถ**
  - 7 แบบ ใช้ฟิสิกส์ช่วงล่าง วิ่งเลนขวาแบบอเมริกา
  - มีการจราจรจริง, แย่งรถได้, ซื้อรถได้, เรียกรถมาหาได้
  - รถพังจนระเบิดได้
  - มุมกล้องในรถทั้งบุคคลที่ 1 และ 3, มีวิทยุ 4 สถานี

**เนื้อเรื่อง**
- เนื้อเรื่องหลัก "Static Saints" มี 7 บทและ **4 ฉากจบ**
- ทางเลือกในบทสนทนาส่งผลต่อเรื่อง และมีการเช็คค่าสถานะ เช่น `[COOL 5]`, `[TECH 5]` รวมถึงตัวเลือกที่เปิดเฉพาะบางภูมิหลัง
- เควสต์รอง 4 เควสต์
- งานจ้าง (gig) สุ่มจาก fixer 3 คน และบอร์ดค่าหัวของตำรวจ
- แข่งรถ 3 สนาม (เหรียญทอง/เงิน/ทองแดง และบันทึกสถิติ), สังเวียนต่อยใต้ดิน 3 ยก
- เหตุการณ์สุ่มทั่วเมือง: รีดไถ, แก๊งยิงกัน, Burnout (บอสไซบอร์กคลั่ง), กล่องเสบียงตกจากฟ้า, ตำรวจบุกจับ
- Data shard ให้เก็บ 20 ชิ้น, เมโทรเดินทางเร็ว, ห้องพักของตัวเองไว้นอนข้ามเวลาและเซฟ

**เสียงและ UI**
- เสียงทุกเสียงสังเคราะห์ด้วยโค้ด
- เพลงสร้างแบบเรียลไทม์ และเปลี่ยนเป็นเพลงตื่นเต้นเองตอนต่อสู้
- HUD มีมินิแมพ, เข็มทิศ, ตัวติดตามเควสต์ และเลขดาเมจ
- แผนที่เต็มจอ ปักหมุดได้
- เซฟได้ 3 ช่อง, มี autosave และ quicksave
- หน้าตั้งค่า: ความไวเมาส์, FOV, เสียง, คุณภาพกราฟิก, ระยะมองเห็น, ขนาด UI

## โครงสร้างโค้ด (`Assets/NeonBay/Scripts`)

| โฟลเดอร์ | หน้าที่ |
|---|---|
| `Core` | GameManager (เริ่มเกม, เซฟ/โหลด, state), InputHub (รองรับทั้ง Input Manager เก่าและ Input System ใหม่), Settings |
| `Rendering` | สร้าง material/texture/mesh ด้วยโค้ด, Post-processing ของ URP |
| `World` | สร้างเมือง, chunk streaming + light pool, กลางวัน/กลางคืน/อากาศ, NavMesh แบบ runtime, จราจร, ฝูงชน, เหตุการณ์สุ่ม |
| `Player` | การเคลื่อนที่ FPS, ค่าสถานะ RPG, กระเป๋า, การแฮ็ก, การโต้ตอบ |
| `Combat` | อาวุธ, viewmodel, เอฟเฟกต์, ระเบิด |
| `AI` | ตัวละครและ ragdoll, AI ของ NPC, ฝ่ายต่าง ๆ, ตำรวจ, โดรน |
| `Vehicles` | ฟิสิกส์รถ + โมเดลรถ |
| `Quests` | ระบบเควสต์, บทสนทนา, เนื้อเรื่อง, กิจกรรม, lore |
| `UI` | UI ทั้งหมด (IMGUI): HUD, เมนู, สร้างตัวละคร, แผนที่, ร้านค้า |
| `Audio` | เครื่องสังเคราะห์เสียง, ระบบเล่นเสียง, เพลง |

## ข้อจำกัดที่ควรรู้

- **กราฟิก**: ไม่มีโมเดลหรือ texture จากศิลปิน ทุกอย่างสร้างด้วยโค้ด ภาพที่ได้คือเมืองนีออนตอนกลางคืน มีฝน หมอก bloom และพื้นสะท้อนแสง ซึ่งดูมีบรรยากาศ แต่ตัวละครยังเป็นหุ่นที่ประกอบจากรูปทรงพื้นฐาน ถ้าอยากได้ระดับ AAA ต้องเอาโมเดลจริงมาใส่ (เช่นจาก Mixamo หรือ Asset Store)
- **การทดสอบ**: โค้ดทั้งหมดคอมไพล์ผ่านกับ reference assembly ของ Unity ทั้งโหมด Input Manager เก่าและ Input System ใหม่ รวมถึงสคริปต์ฝั่ง Editor แต่ **ยังไม่เคยกด Play ใน Unity Editor จริง** ถ้าเจอ error ใน Console ให้ส่งข้อความนั้นมาแก้ต่อ
