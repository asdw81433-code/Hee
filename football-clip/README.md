# คลิป "นักพากย์โลกสวย" ⚽😇

ระบบตัดต่ออัตโนมัติ เอาคลิปฟุตบอลจริงมาตัดเป็นแนวตั้ง (1080x1920) พร้อมซับพากย์แบบตรงข้ามกับภาพ

## ต้องมี
- Python 3
- ffmpeg (Windows: `winget install ffmpeg` / Mac: `brew install ffmpeg`)
- ฟอนต์ไทย ค่าเริ่มต้นคือ `Loma` แต่เปลี่ยนเป็น `Tahoma`, `Leelawadee UI` หรือ `Kanit` ได้ที่ `font` ใน `shots.json`

## หาคลิป
ค้นใน YouTube แล้วโหลดมาไว้ใน `clips/` โดยตั้งชื่อไฟล์ตามนี้

| ไฟล์ | คีย์เวิร์ดค้นหา |
|---|---|
| neymar.mp4  | neymar rolling world cup 2018 |
| suarez.mp4  | suarez bites chiellini 2014 |
| ramos.mp4   | ramos salah arm lock 2018 |
| karius.mp4  | karius benzema mistake 2018 final |
| dicanio.mp4 | di canio pushes referee 1998 |
| zidane.mp4  | zidane headbutt materazzi 2006 |

## ตั้งเวลาให้ตรงจังหวะ
ใน `shots.json` ให้แก้ 2 ค่านี้ของแต่ละช็อต
- `start` คือวินาทีที่เริ่มตัด (ให้เริ่มก่อนจังหวะสำคัญประมาณ 1–2 วินาที)
- `dur` คือความยาวที่ตัด หน่วยเป็นวินาที

ตั้ง `"slowmo": true` ถ้าอยากให้ช็อตนั้นช้าลง 2 เท่า ส่วนข้อความพากย์ก็แก้ที่ `text` ได้เลย (ใช้ `\n` เพื่อขึ้นบรรทัดใหม่)

## รัน
```
python3 make_clip.py
```
จะได้ไฟล์ `output.mp4` ถ้าวางไฟล์ `music.mp3` ไว้ในโฟลเดอร์นี้ ระบบจะใส่เป็นเพลงประกอบให้อัตโนมัติ (แนะนำเพลงเปียโนหวานๆ หรือเพลงกล่อมเด็ก)

## ต่อใน CapCut (ถ้าอยากใส่เพิ่ม)
- ใส่เสียงพากย์ด้วย Text-to-Speech ของ CapCut โดยก๊อปข้อความจาก `shots.json` ไปใช้
- ใส่สติกเกอร์หัวใจ ✨ หรือ 😇 ตอนจังหวะกระแทก
- ใส่ฟรีซเฟรมตรงจังหวะที่คนล้ม

## เวอร์ชันการ์ตูน (ไม่ต้องหาคลิป)
```
python3 cartoon_clip.py
```
วาดทุกฉากเองเป็นแอนิเมชัน ทั้งสไลด์สกัด ดึงเสื้อ พุ่งล้ม โกลหลีกทาง ยิงข้ามคาน ใบแดง และซบอก มีเพลงกล่อมที่แต่งขึ้นเอง เสียงกระแทก และเสียงนกหวีด
ได้ไฟล์ `output_cartoon.mp4` ยาว 41 วินาที ขนาด 1080x1920 ไม่ติดลิขสิทธิ์
