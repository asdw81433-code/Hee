# สังเวียนเลือด: CAGE BLOOD

เกม MMA แนวแซนด์บ็อกซ์บนเว็บ เปิดใน browser ได้เลยไม่ต้องติดตั้งอะไร ตัวละครเป็นทรงเหลี่ยม low-poly (กราฟิกมันฝรั่ง) ใบหน้าวาดเองได้แบบสมจริง มีระบบเลือดและอาการบาดเจ็บที่ละเอียด ฟิสิกส์ร่างกายจริง และโหมดอาชีพพร้อมเนื้อเรื่อง

> ชื่อโปรโมชัน ตัวละคร และนักสู้ทั้งหมดในเกมเป็นเรื่องสมมติ ไม่ได้อ้างอิงองค์กรหรือบุคคลจริง

## ระบบหลัก

### ฟิสิกส์และแอนิเมชัน (ไม่มีท่าอัดไว้ล่วงหน้า ทุกท่าคำนวณสดด้วยฟิสิกส์)
- ข้อต่อลำตัวขับด้วย **PD controller (สปริง + แดมเปอร์)** ร่างกายจึงมีน้ำหนัก มีแรงเฉื่อย มีจังหวะตามหลัง ไม่แข็งทื่อแบบหุ่นยนต์
- แขนและขาใช้ **2-bone IK** หมัดพุ่งไปยังตำแหน่งเป้าหมายจริง ถ้าคู่ชกหลบ หมัดก็พลาดจริง
- **Kinetic chain:** เท้า → สะโพก → ลำตัว → แขน หมัดตรงหลังหมุนสะโพกและบิดส้นเท้าหลัง ส่วนเตะวงกลมมีการ chamber เข่า บิดเท้าหลักและเอนตัว ความเร็วของกำปั้นจึงเกิดจากการหมุนของลำตัวจริงๆ
- ฟุตเวิร์กแบบ **step-and-drag** ตามหลักวางเท้าแบบ SIMBICON เดินหน้าเท้าหน้าออกก่อน ถอยหลังเท้าหลังออกก่อน
- **ความแรงคำนวณจากฟิสิกส์:** ใช้ความเร็วสัมพัทธ์ของกำปั้นหรือแข้งตอนกระทบ (∝ v²) หมัดสวนจึงแรงกว่า หมัดที่ยังไม่สุดก็เบากว่า
- โดนหมัดแล้วหัวสะบัดตามแรงบิดจริงที่เกิดจาก (จุดกระทบ × ทิศแรง)
- น็อกแล้วเปลี่ยนเป็น **Verlet ragdoll** โดยต่อโมเมนตัมจากท่าเดิม บางครั้งเกิด fencing response (แขนเกร็งชูขึ้น) มีรีเพลย์สโลว์โมชันตอนน็อก
- โดนหนักแล้วขาอ่อน ร่างกายโยกเหมือนคนเมา ลุกจากพื้นด้วยท่า technical stand-up

### เลือด (ตั้งใจทำให้สมจริงที่สุดในกราฟิกมันฝรั่ง)
- หยดเลือดบินตามกฎฟิสิกส์ มีแรงโน้มถ่วงและแรงต้านอากาศตามขนาดหยด ระหว่างบินหยดจะยืดตามความเร็ว
- คราบบนพื้นยืดตามมุมตกกระทบ (กว้าง/ยาว = sin มุม) หยดที่ตกเร็วมีละอองกระเซ็น (satellite spatter) และหาง
- เลือดจากแผลไหลลงหน้าตาม **แรงโน้มถ่วงที่ฉายลงบนระนาบใบหน้า** ถ้าก้มหน้า เลือดหยดจากแผลตรงๆ ถ้านอนหงาย เลือดนองรอบแผล
- เลือดไหลเข้าตาแล้ว **บังการมองเห็นจริง** (หน้าจอฝั่งนั้นแดงเบลอ ส่วน AI จะชกแม่นน้อยลง)
- เลือดไหลจากคางลงคอ หน้าอก และหยดใส่ตัวคู่ชกที่อยู่ด้านล่าง
- นวมเปื้อนเลือดคู่ชก ถ้าต่อยใส่หน้าที่มีเลือดอยู่ เลือดจะสาดออกตามทิศหมัด
- เลือดเปลี่ยนสีจากแดงเป็นน้ำตาลตามเวลา (ออกซิเดชัน) และถูกป้ายเลอะเมื่อร่างกายไถลบนพื้น
- ระหว่างยก ทีมเช็ดหน้าและเช็ดพื้นได้แค่บางส่วน คราบจาง ๆ ยังคงอยู่
- เหงื่อกระเซ็นเมื่อโดนชัดๆ และจะมากขึ้นในยกท้ายๆ

### อาการบาดเจ็บ
- **แผลแตก** เหนือคิ้ว หน้าผาก โหนกแก้ม ปาก แผลจากศอกแตกง่ายกว่าหมัดราว 3 เท่า แผลเดิมที่โดนซ้ำจะลึกขึ้น และ **แผลเป็นสะสมทั้งอาชีพทำให้แตกง่ายขึ้น**
- **บวม:** ตาบวมจนปิด (มีก้อนบวม 3D บนหัว), โหนกแก้ม, หน้าผาก, ปาก
- **กระดูก:** จมูกหัก (จมูกเบี้ยว เลือดกำเดาไหลไม่หยุด หายใจแย่ลง สตามินาฟื้นช้า), เบ้าตาแตก, กรามหัก, มือหัก (จากการต่อยกระดูกแข็ง), ซี่โครงร้าว, แขนหักหรือไหล่ฉีกจากการไม่ยอมตบเวลาโดนล็อก
- **สมอง:** ความรู้สึกตัว (consciousness) ลดลงตามแรงบิดของศีรษะ แบ่งเป็นสามระดับ คือ ขาอ่อน (rocked), น็อกดาวน์ และน็อกเอาต์ หมัดที่หมุนหัวเข้าคางหรือกรามจึงอันตรายกว่าหมัดตรงเข้าหน้าผาก
- **ตับ:** ฮุคซ้ายเข้าลำตัวฝั่งขวาของคู่ชก ทำให้ทรุดลงหลังโดนสักพัก (0.3-1.2 วินาที)
- **ขา:** เตะน่องสะสมจนเส้นประสาท peroneal ชา (dead leg) เดินกะเผลก และขาทรุดเองเมื่อลงน้ำหนัก
- **สตามินา:** หมัดลมเปลืองแรง และหมัดเข้าลำตัวทำให้ถังน้ำมันเล็กลงทั้งไฟต์

### กติกาและการตัดสิน (Unified Rules of MMA)
- ระบบ 10-point must ใช้กรรมการ 3 คน แต่ละคนมีอคติและความคลาดเคลื่อนต่างกัน จึงเกิดคะแนนไม่เอกฉันท์ (split) หรือเสมอได้ เกณฑ์หลักคือ effective striking/grappling แล้วจึงดู aggression และ cage control
- กรรมการห้ามมวยหยุดไฟต์เมื่อเห็นการโดนชกฝ่ายเดียวตอนที่ไม่ได้ป้องกันตัว (TKO) แยกคลินช์ที่นิ่งนาน และสั่งยืนเมื่อบนพื้นไม่มีการเคลื่อนไหว
- **แพทย์ข้างเวที** เข้ามาตรวจแผลได้กลางยก และตรวจซ้ำระหว่างพักยก ถ้าแผลลึกหรือตาบวมปิดอาจสั่งยุติการชก
- **พักยก:** โค้ชให้คำแนะนำตามสถานการณ์ คัทแมนใช้แรงกด อะดรีนาลีน 1:1000 วาสลีน และ Enswell

### ปล้ำ
- คลินช์ (plum / underhook) ปล่อยเข่าและศอกได้ ดันคู่ชกติดกรงได้ ทุ่มจากคลินช์ได้
- ยิงเทคดาวน์ได้ทั้งตอนคู่ชกยืน และพุ่งเข้าใส่ตอนคู่ชกล้ม ฝ่ายรับสปรอลกันได้ หรือสวนเข่าตอนอีกฝ่ายก้มตัวมา ซึ่งชนกันจริงตามฟิสิกส์ ถ้าสปรอลสำเร็จจะได้ front headlock และโอกาสล็อกกิโยตีน
- ตำแหน่งบนพื้นมี closed guard, half guard, side control, mount, back control ฝ่ายบนไล่ตำแหน่งได้ ฝ่ายล่างสวีปหรือหนีได้ ทุบจากด้านบนได้ (ground & pound) และลุกขึ้นยืนได้
- ซับมิชชัน: RNC, arm-triangle, kimura, armbar, triangle, guillotine เป็นมินิเกมแย่งแรงกัน ถ้าไม่ยอมตบ ท่ารัดคอทำให้หลับ ส่วนท่าล็อกข้อทำให้แขนหัก

### โหมดอาชีพ (ระบบลึก)
- **ซ้อมรายสัปดาห์:** เลือกได้ 3 อย่างจาก 15 กิจกรรม เช่น สปาร์หนัก/เบา ล่อเป้า มวยปล้ำ BJJ S&C คาร์ดิโอ ดูเทปคู่ชก คุมอาหาร พักฟื้น งานสื่อ ทำงานพิเศษ หรือใช้เวลากับครอบครัว
- **ความล้าและการซ้อมเกิน (overtraining):** ทำให้บาดเจ็บระหว่างซ้อมได้ เช่น ข้อเท้าพลิก นิ้วหัก หมอนรองกระดูกปลิ้น หรือโดนน็อกในการสปาร์
- **สมองเสียหายสะสม (CTE):** เพิ่มจากการสปาร์หนักและไฟต์ และไม่มีวันลดลง คางจะอ่อนลงถาวร ทำให้ถูกน็อกง่ายขึ้นในไฟต์ต่อๆ ไป
- **อายุ:** พัฒนาเร็วตอนหนุ่ม พีคราว 27-32 ปี หลังจากนั้นความเร็ว คาร์ดิโอ และคางจะถดถอย
- **น้ำหนักตัว:** ชั่งน้ำหนักก่อนไฟต์ ถ้าต้องรีดน้ำมาก คาร์ดิโอกับคางจะแย่ลงในไฟต์ ถ้าชั่งไม่ผ่านจะถูกปรับ 20%
- **เงินและสัญญา:** ค่าตัวแบบ show/win ต่อรองได้ (มีโอกาสที่ข้อเสนอจะถูกถอน) ไฟต์แจ้งล่วงหน้าสั้นได้ค่าตัวเพิ่ม 40% มีโบนัส Performance/Fight of the Night สปอนเซอร์ ค่าครองชีพ และค่ายิม
- **Medical suspension:** หลังไฟต์ต้องพักตามอาการ เช่น แพ้น็อกพัก 9 สัปดาห์ จมูกหักพัก 6 สัปดาห์ เบ้าตาแตกพัก 12 สัปดาห์
- **ยิม:** มีให้เลือก 5 แห่ง แต่ละแห่งมีจุดเด่นและค่าใช้จ่ายต่างกัน ถ้าย้ายออกจากยิมครูเดช ความสัมพันธ์กับครูจะลดลง
- **โลกที่มีชีวิต:** นักสู้ NPC ชกกันเองทุกสัปดาห์ อันดับในรุ่นเปลี่ยนตลอด และแชมป์เปลี่ยนมือได้

### เนื้อเรื่อง
เพื่อนรัก "ต้น" สมองบาดเจ็บจากไฟต์ใต้ดินของโปรโมเตอร์ "วิกเตอร์ สโตน" ค่ารักษา 40,000 ดอลลาร์ถูกเขียนเป็นหนี้ในชื่อคุณ คุณจึงต้องขึ้นชก โดยมี "ครูเดช" ครูมวยแก่ที่ป่วยเป็น CTE เป็นคนสอน ระหว่างทางจะต้องตัดสินใจหลายเรื่อง เช่น จะให้วิกเตอร์เป็นผู้จัดการไหม จะยอมล้มมวยหรือไม่ จะขึ้นให้การร่วมกับนักข่าวหรือเปล่า จะช่วยค่าผ่าตัดต้นไหม และจะเลิกชกเมื่อหมอเตือนหรือไม่ ทุกการตัดสินใจนำไปสู่ฉากจบที่ต่างกัน เช่น "ตำนานที่ยังจำชื่อตัวเองได้", "ราคาของเข็มขัด", "หนี้เลือด", "ไม่มีเข็มขัด แต่มีชีวิต" ถ้าสมองเสียหายสะสมมาก ข้อความในเนื้อเรื่องจะเริ่มเพี้ยน

### สร้างตัวละคร
- **วาดหน้าเองบนหัวเหลี่ยม** มีพู่กัน ยางลบ (สีผิว) เบลอ/เกลี่ย ดูดสี วาดสมมาตร เส้นนำตำแหน่ง ย้อนกลับ สุ่มใบหน้าสมจริง และนำเข้ารูปถ่าย
- เส้นนำช่วยวางคิ้ว ตา จมูก ปาก ให้ตรงจุดที่ระบบบาดแผลใช้ แผลแตกเหนือคิ้วจึงขึ้นตรงคิ้วที่วาดไว้จริง
- ปรับร่างกายได้: รุ่นน้ำหนัก 8 รุ่น ส่วนสูง ช่วงแขน น้ำหนักตัวปกติ กล้ามเนื้อ ไขมัน สีผิว ทรงผม หนวด กางเกง รอยสัก (มีสักยันต์) หูกะหล่ำ
- เลือกพื้นฐานการต่อสู้ 8 แบบ แจกแต้มค่าพลัง 24 ด้าน และดูตัวอย่าง 3D ที่ชกลมอยู่กลางกรงได้ทันที

## สำหรับนักพัฒนา

```
npm install          # three.js + esbuild
npm run build        # รวม src/ เป็น index.html ไฟล์เดียว (ใช้งานออฟไลน์ได้)
node build.mjs --dev # build แบบไม่ minify
```

| ไฟล์ | หน้าที่ |
|---|---|
| `src/rig.js` | โครงกระดูก, สปริง PD, IK, Verlet ragdoll |
| `src/fighter.js` | ฟุตเวิร์ก, ท่าโจมตี, การตรวจจับการชน, ปฏิกิริยาเมื่อโดนชก, ล้มและลุก |
| `src/moves.js` | ข้อมูลท่าโจมตี (เวลาและ kinetic chain) |
| `src/injury.js` | ระบบบาดเจ็บและสรีรวิทยา |
| `src/blood.js` · `src/face.js` | หยดเลือด, คราบเลือด, ใบหน้าที่วาด, บาดแผล, เลือดไหลบนผิว |
| `src/grapple.js` | คลินช์, เทคดาวน์, ตำแหน่งบนพื้น, ซับมิชชัน |
| `src/ai.js` | สมอง AI |
| `src/fight.js` | กติกา, กรรมการห้ามมวย, กรรมการให้คะแนน, แพทย์, รีเพลย์ |
| `src/career.js` · `src/story.js` | โหมดอาชีพและเนื้อเรื่อง |
| `src/creator.js` · `src/ui.js` · `src/hud.js` | สร้างตัวละคร, เมนู, HUD |

การทดสอบอัตโนมัติ (ใช้ Playwright) อยู่ในโฟลเดอร์ `test/`: `shot.mjs` สำหรับถ่ายภาพไฟต์ AI (`index.html?test=1&warp=6`), `ui.mjs` สำหรับ flow เมนูและโหมดอาชีพ, `play.mjs` สำหรับทดสอบปุ่มควบคุม, `multi.mjs` สำหรับความเสถียรเมื่อเล่นหลายไฟต์ติดกัน และ `careersim.mjs` ที่จำลองอาชีพหลายร้อยสัปดาห์
