# ซอยเดือด : SOI BRAWL 🔥👊 (Roblox)

เกมตีกันข้างถนนสำหรับ Roblox ตัวละครเป็นบล็อกเหลี่ยมตามภาพอ้างอิง (เสื้อยืดเทา กางเกงเขียว ผมทรงกล่อง หน้าวาดแบบพิกเซล)
ฉากเป็นซอยตึกแถว มีเสาไฟ สายไฟพันกัน ตุ๊กตุ๊ก รถเข็นหมูปิ้ง และสังเวียนข้างทาง
ระบบเด่น: **ragdoll ฟิสิกส์จริง**, เลือดหยดติดพื้นและกำแพง, ฟันกระเด็น, หน้าแตกตาเขียวสะสม, อาวุธข้างถนน, บอท AI, รอบ 3 นาที และปุ่มมือถือแบบรูป

> ทุกอย่างสร้างด้วยโค้ด ทั้งแมพ ตัวละคร หน้า และอาวุธ ไม่ต้องหา asset มาใส่

---

## วิธีเปิดเล่น (เลือกแบบเดียว)

### แบบที่ 1: เปิดไฟล์เดียวจบ (ง่ายสุด)
1. ดาวน์โหลดไฟล์ `Roblox/SoiBrawl.rbxlx`
2. เปิด **Roblox Studio** แล้วไปที่ **File → Open from File…** เลือก `SoiBrawl.rbxlx`
3. กด **Play** (F5) แมพจะสร้างตัวเองตอนเริ่มเกม
   - ตอนยังไม่กด Play จะเห็นโลกว่างๆ เป็นเรื่องปกติ
4. ถ้าจะอัปขึ้น Roblox ให้กด **File → Publish to Roblox**

### แบบที่ 2: ก๊อปโค้ดใส่เอง (ใช้กับ place ที่มีอยู่แล้วได้)
สร้างสคริปต์ตามตารางนี้ (คลิกขวา → Insert Object) แล้วก๊อปโค้ดจากไฟล์มาวางให้ **ชื่อตรงเป๊ะ**

| วางไว้ที่ | ชนิด | ชื่อ | ก๊อปจากไฟล์ |
|---|---|---|---|
| ReplicatedStorage | ModuleScript | `BrawlConfig` | `src/shared/BrawlConfig.lua` |
| ReplicatedStorage | ModuleScript | `BrawlAnim` | `src/shared/BrawlAnim.lua` |
| ServerScriptService | **Script** | `BrawlServer` | `src/server/init.server.lua` |
| ↳ ข้างใน BrawlServer | ModuleScript | `MapBuilder` | `src/server/MapBuilder.lua` |
| ↳ ข้างใน BrawlServer | ModuleScript | `CharacterBuilder` | `src/server/CharacterBuilder.lua` |
| ↳ ข้างใน BrawlServer | ModuleScript | `Ragdoll` | `src/server/Ragdoll.lua` |
| ↳ ข้างใน BrawlServer | ModuleScript | `Combat` | `src/server/Combat.lua` |
| ↳ ข้างใน BrawlServer | ModuleScript | `Weapons` | `src/server/Weapons.lua` |
| ↳ ข้างใน BrawlServer | ModuleScript | `Bots` | `src/server/Bots.lua` |
| StarterPlayer → StarterPlayerScripts | **LocalScript** | `BrawlClient` | `src/client/init.client.lua` |
| ↳ ข้างใน BrawlClient | ModuleScript | `Animator` | `src/client/Animator.lua` |
| ↳ ข้างใน BrawlClient | ModuleScript | `Effects` | `src/client/Effects.lua` |

- Baseplate และ SpawnLocation เดิมจะถูกลบให้อัตโนมัติตอนเริ่มเกม กันพื้นซ้อนกัน

### แบบที่ 3: Rojo (สำหรับคนเขียนโค้ด)
```
cd Roblox
rojo serve      # แล้วกด Connect ใน Rojo plugin
# หรือ
rojo build -o SoiBrawl.rbxlx
```
ถ้าแก้โค้ดใน `src/` แล้วอยากได้ไฟล์ `.rbxlx` ใหม่โดยไม่ใช้ Rojo ให้รัน `node tools/build-place.mjs`

## ความโหด + ความฮา

- **Ragdoll จริง**: ข้อต่อเปลี่ยนเป็น BallSocketConstraint มีมุมจำกัดแบบคน ร่างลอยไปชนกำแพง พื้น หรือเชือกสังเวียนจะเด้งจริง
  - ชนแรงจะเจ็บเพิ่ม ขึ้นคำว่า "โครม!!" และมีเลือด
- **เลือด**: หยดเลือดบินตามทิศหมัด ตกพื้น/กำแพงแล้วเป็นรอย รอยค่อยๆ แห้งเข้มขึ้น คนที่ KO จะมีแอ่งเลือดค่อยๆ ขยาย
- **หน้าพัง**: ยิ่งโดนหน้ายิ่งเลือดกำเดาไหล คิ้วแตก ตาเขียว มุมปากแตก และเลือดหยดลงเสื้อ
- **ฟันกระเด็น 🦷** เมื่อโดนอัปเปอร์คัต หมัดจรวด หรือคริติคอล
- **มึนหัว 💫** เมื่อโดนติดๆ กัน: เดินเซ หน้าเป็นตา @ @ และโดนตีเจ็บขึ้น
- **อาวุธข้างถนน** (เกิดบนแท่นสีเหลือง):
  - 🍳 กระทะเหล็ก
  - 🪵 ไม้หน้าสาม
  - 🪑 เก้าอี้พลาสติก (ฟาดทีลอย แตกได้)
  - 🐟 ปลาทูยักษ์ (เจ็บน้อยแต่ปลิวไกลมาก)
  - 🔺 กรวยจราจร (ครอบหัวคนโดน)
  - 🧴 ขวดน้ำปลา (แตกคาหัว)
- **ของในแมพ**:
  - กระจกหน้าร้านแตกได้ถ้ามีร่างบินเข้าไปชน
  - แตงโมบนรถเข็นแตกกระจาย
  - ถังขยะ กล่อง เก้าอี้พลาสติก และโต๊ะเตะกระจายได้
  - ศพเตะเล่นได้
- **ฮา**:
  - คำการ์ตูนภาษาไทยเด้ง เช่น "ปั้ก!" "เป๊ง!!" "ซูเพล็กซ์!!"
  - ข้อความ KO ฮาๆ
  - ฉายาตอนล่าต่อเนื่อง 🔥👹💀
  - รางวัลจบรอบ:
    - 👑 ราชาซอย
    - 💪 หมัดหนักสุด
    - 🥔 กระสอบทรายแห่งปี
    - 💃 นักเต้นแห่งซอย
  - บอทชื่อฮาๆ เช่น "ป้าแจ่ม กระทะทอง" และ "ไอ้ตี๋ หมัดเมา"

## ปรับแต่ง (ไฟล์ `BrawlConfig`)
- `BotCount`, `BotSkill`: จำนวนบอทกับความเก่ง (0 ถึง 1)
- `RoundTime`: ความยาวรอบ
- `MaxHealth`, `WalkSpeed`: เลือดและความเร็ว
- `Blood`:
  - `0` = ไม่มีเลือด (ขึ้นดาวการ์ตูนแทน)
  - `0.5` = น้อย
  - `1` = ปกติ
  - `2` = สาดกระจาย
- `Teeth`, `FaceDamage`: เปิด/ปิดฟันหลุดและหน้าเลือด
- `Moves`: ดาเมจ ระยะ แรงผลัก และเวลาล้มของทุกท่า
- `Weapons`: ค่าของอาวุธแต่ละชิ้น
- `Look`: สีผิว เสื้อ กางเกง ผม และทรงผม
  - ทรงผมที่มี: `box`, `flat`, `spike`, `mohawk`, `bald`, `cap`, `long`, `afro`
- `Words`, `KOMessages`, `BotNames`: ข้อความทั้งหมดในเกม
- `Sounds`: ตอนนี้ใช้เสียงที่ติดมากับ Roblox ถ้าอยากได้เสียงหมัดเจ๋งๆ ให้เปลี่ยนเป็น `rbxassetid://เลขเสียง` จาก Creator Store

> ⚠️ **ก่อนเปิดเกมสาธารณะ**: เกมนี้มีเลือดและความรุนแรง ต้องกรอกแบบสอบถาม **Maturity & Compliance** ใน Creator Hub ตามจริง
> ถ้าอยากให้เด็กเล่นได้ ให้ตั้ง `Blood = 0`

## โครงสร้างโค้ด
```
Roblox/
  SoiBrawl.rbxlx           ← ไฟล์ place พร้อมเปิด
  default.project.json     ← สำหรับ Rojo
  tools/build-place.mjs    ← สร้าง .rbxlx ใหม่จาก src/
  src/shared/   BrawlConfig (ค่าทั้งหมด), BrawlAnim (ท่าทาง keyframe)
  src/server/   init.server (รอบ/ผู้เล่น/บอท), MapBuilder, CharacterBuilder, Ragdoll, Combat, Weapons, Bots
  src/client/   init.client, Animator (สปริง+procedural), Effects (เลือด/คำ/เสียง/กล้องสั่น), Hud, Controls
```
- **Server เป็นคนตัดสินการโดนทั้งหมด** (กันโกงเบื้องต้น) แล้วส่งเอฟเฟกต์ไปทุกเครื่อง
- **แอนิเมชันทำในเครื่องผู้เล่น**: ใช้ keyframe ร่วมกับสปริงที่มีการเด้งเล็กน้อย ตัวละครเลยมีน้ำหนัก ไม่แข็งทื่อ
- ตอนตีโดนจะมี hit-stop หยุดภาพแป๊บเดียวให้รู้สึกถึงแรงกระแทก

## การทดสอบที่ทำแล้ว
- ตรวจ syntax และตัวแปร global ทุกไฟล์
- รันโค้ดจริงในตัวจำลอง Roblox API: server 130 วินาทีเกม (บอท 5 ตัว ผู้เล่น 2 คน) และ client ทั้งโหมดคีย์บอร์ดกับมือถือ ไม่พบ error
  - ทดสอบแล้ว: คอมโบ ตีโดน KO เกิดใหม่ หยิบและขว้างอาวุธ กระจกแตก แตงโมแตก หมัดจรวด จบรอบ ตกแมพ และผู้เล่นออกเกม
- ตรวจท่าทางทุกท่าด้วยภาพเรนเดอร์ 3D
- **ยังไม่ได้ทดสอบใน Roblox Studio จริง** ถ้าเจอ error ใน Output ส่งข้อความมาได้เลย
- รันชุดตรวจเองได้: `cd Roblox/tools && npm install && npm run check && npm run test:server && npm run test:client`
