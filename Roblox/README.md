# ALLEY BRAWL 🔥👊 (Roblox)

เกมตีกันข้างถนนสำหรับ Roblox สไตล์เกมฝรั่ง ข้อความในเกมเป็นภาษาอังกฤษทั้งหมด

- **ตัวละคร:** ร่าง ragdoll สัดส่วนคนจริงสไตล์เกม gore sandbox แยก 15 ชิ้น มือและเท้าแยกชิ้น ข้อต่อกลม 14 ข้อ (ออกแบบเอง ไม่ได้ใช้โมเดลของเกมอื่น)
- **แขนขาหลุดได้ทุกข้อ:** มีตอเนื้อแดง กระดูก และเลือดพุ่งเป็นจังหวะ ท่าแรงๆ หัวหลุดหรือขาดครึ่งท่อนได้
- **ฉาก:** ตรอกในเมืองอเมริกาที่เป็นชิ้นงานจริงในไฟล์ เปิดใน Studio แล้วเห็นและแก้ได้ทันที
  - ตึกอิฐ บันไดหนีไฟ กันสาดหน้าร้าน ป้ายร้านภาษาอังกฤษ ถังน้ำบนหลังคา
  - แท็กซี่เหลือง รถเข็นฮอทด็อก ถังขยะใหญ่ หัวดับเพลิง เสาไฟฟ้าไม้
  - สังเวียน FIGHT NIGHT กลางถนน มีเก้าอี้พับรอบเวที
- **ระบบอื่น:**
  - ragdoll ฟิสิกส์จริง เลือดหยดติดพื้นและกำแพง แผลติดตามตัว ฟันกระเด็น
  - อาวุธข้างถนน บอท AI รอบละ 3 นาที
  - ปุ่มมือถือแบบรูป

> แมพ แสง และโมเดลผู้เล่นถูกบันทึกไว้ในไฟล์ `.rbxlx` เป็นชิ้นงานจริง ส่วนสคริปต์ยังสร้างแมพเองได้ถ้าก๊อปไปใส่ place อื่นที่ไม่มีแมพ

## วิธีเปิดเล่น (เลือกแบบเดียว)

### แบบที่ 1: เปิดไฟล์เดียวจบ (ง่ายสุด)
1. ดาวน์โหลดไฟล์ `Roblox/AlleyBrawl.rbxlx`
2. เปิด **Roblox Studio** แล้วไปที่ **File → Open from File…** เลือก `AlleyBrawl.rbxlx`
3. จะเห็นแมพทั้งแมพใน Workspace (โฟลเดอร์ `AlleyMap`) แก้ ย้าย หรือลบชิ้นไหนก็ได้
4. กด **Play** (F5) เพื่อเล่น
5. ถ้าจะอัปขึ้น Roblox ให้กด **File → Publish to Roblox** (อ่านคำเตือนเรื่องความรุนแรงด้านล่างก่อน)

#### แก้แมพ / แก้ตัวละครใน Studio
- **แมพ:** อยู่ที่ `Workspace > AlleyMap`
  - บล็อกสีเขียวใส `SpawnPoint` = จุดเกิด (ย้ายได้ ตอนเล่นจะล่องหน)
  - แท่นเหลือง `WeaponPad` = จุดเกิดอาวุธ (ย้ายได้)
  - ชิ้นชื่อ `ShopGlass` = กระจกที่แตกได้, ชิ้นชื่อ `Watermelon` = แตงโมที่แตกได้
- **ตัวละคร:** อยู่ที่ `ServerStorage > Brawler` ลากเข้า Workspace เพื่อดูหรือแก้ได้ แต่ต้องลากกลับไปไว้ที่ ServerStorage
  - เปลี่ยนขนาดชิ้นหรือเพิ่มของแต่งตัวได้ ต้องคงชื่อชิ้นหลักกับชื่อข้อต่อ (Motor6D) ไว้เหมือนเดิม
  - ถ้ามีโมเดล MeshPart ของตัวเอง เอามาแทนชิ้นเดิมโดยตั้งชื่อชิ้นให้ตรงได้
  - สีเสื้อ/กางเกง/ผิวจะถูกระบายใหม่ตาม `BrawlConfig.Look`
  - ถ้าลบ `Brawler` ทิ้ง เกมจะสร้างตัวละครจากโค้ดแทน

### แบบที่ 2: ก๊อปโค้ดใส่เอง (ใช้กับ place ที่มีอยู่แล้วได้)
สร้างสคริปต์ตามตารางนี้ (คลิกขวา → Insert Object) แล้วก๊อปโค้ดจากไฟล์มาวางให้ **ชื่อตรงเป๊ะ**

| ReplicatedStorage | ModuleScript | `BrawlAnim` | `src/shared/BrawlAnim.lua` |
| ServerScriptService | **Script** | `BrawlServer` | `src/server/init.server.lua` |
| ↳ ข้างใน BrawlServer | ModuleScript | `MapBuilder` | `src/server/MapBuilder.lua` |
| ↳ ข้างใน BrawlServer | ModuleScript | `CharacterBuilder` | `src/server/CharacterBuilder.lua` |
| ↳ ข้างใน BrawlServer | ModuleScript | `Ragdoll` | `src/server/Ragdoll.lua` |
| ↳ ข้างใน BrawlServer | ModuleScript | `Combat` | `src/server/Combat.lua` |

- Baseplate และ SpawnLocation เดิมจะถูกลบให้อัตโนมัติตอนเริ่มเกม กันพื้นซ้อนกัน
- แบบนี้ไม่มีแมพในไฟล์ สคริปต์จะสร้างแมพตอนกด Play แทน

### แบบที่ 3: Rojo (สำหรับคนเขียนโค้ด)
```
cd Roblox
rojo serve      # แล้วกด Connect ใน Rojo plugin
# หรือ
rojo build -o AlleyBrawl.rbxlx
```
- ถ้าใช้ Rojo แมพจะถูกสร้างตอนกด Play
- ถ้าอยากได้ไฟล์ `.rbxlx` ที่มีแมพกับโมเดลจริงอยู่ในไฟล์ ให้รัน `cd tools && npm install && npm run place`

## ร่าง ragdoll สไตล์ gore sandbox 🩸
- **15 ชิ้น:**
  - ช่วงบน: หัว อกบน อกล่าง
  - แขน: ต้นแขน ปลายแขน มือ (×2)
  - ขา: ต้นขา หน้าแข้ง เท้า (×2)
- **14 ข้อต่อ:** คอ เอว ไหล่ ศอก ข้อมือ สะโพก เข่า ข้อเท้า
  - ตอนเดินหรือออกท่า ข้อต่อเป็น Motor6D: เข่างอตอนเดิน ศอกงอตอนการ์ด
  - ตอนล้มหรือตาย ทุกข้อเป็นลูกหมาก (BallSocket) มีมุมจำกัดแบบคนจริง ศอกและเข่าพับทางเดียว
- **โดนตรงไหนเจ็บตรงนั้น:**
  - แต่ละชิ้นเก็บดาเมจแยกกัน และมีแผลเลือดแปะตรงจุดที่โดน
  - โดนชิ้นเดิมหนักๆ (`LimbHP`) ชิ้นนั้นหลุด พร้อมทุกชิ้นที่ต่ออยู่ปลายทาง เช่น ไหล่ขาด = ต้นแขน + ปลายแขน + มือ หลุดไปด้วยกัน
  - ตอที่เหลือมีเนื้อแดง กระดูก และเลือดพุ่งเป็นจังหวะหัวใจ
  - **แขนขาด** ต่อยเบาลง **ขาขาดข้างเดียว** เดินกะเผลก **ขาขาดสองข้าง** ต้องคลาน
  - **หัวหลุด** และ **ขาดครึ่งท่อน** เกิดได้ตอนโดนน็อคด้วยท่าแรง (`DecapChance`, `HalfChance`)
  - กระทืบหรือตีศพ ชิ้นส่วนหลุดได้เหมือนกัน
- ปรับได้ที่ `BrawlConfig`:
  - `Dismember`
  - `GoreLevel` (0 = หลุดแบบบล็อกไม่มีเลือด, 1 = มีตอแดงและเลือด)
  - `LimbHP`, `MinSeverHit`, `GibLife`

## ความโหด + ความฮา

- **Ragdoll จริง**: ข้อต่อเปลี่ยนเป็น BallSocketConstraint มีมุมจำกัดแบบคน ร่างลอยไปชนกำแพง พื้น หรือเชือกสังเวียนจะเด้งจริง
  - ชนแรงจะเจ็บเพิ่ม ขึ้นคำว่า "โครม!!" และมีเลือด
- **เลือด**: หยดเลือดบินตามทิศหมัด ตกพื้น/กำแพงแล้วเป็นรอย รอยค่อยๆ แห้งเข้มขึ้น คนที่ KO จะมีแอ่งเลือดค่อยๆ ขยาย
- **หน้าพัง**: ยิ่งโดนหน้ายิ่งเลือดกำเดาไหล คิ้วแตก ตาเขียว มุมปากแตก และเลือดหยดลงเสื้อ
- **ฟันกระเด็น 🦷** เมื่อโดนอัปเปอร์คัต หมัดจรวด หรือคริติคอล
- **มึนหัว 💫** เมื่อโดนติดๆ กัน: เดินเซ หน้าเป็นตา @ @ และโดนตีเจ็บขึ้น
- **อาวุธข้างถนน** (เกิดบนแท่นสีเหลือง):
  - 🍳 Frying Pan (กระทะ)
  - 🪵 2x4 With A Nail (ไม้ตอกตะปู)
  - 🪑 Folding Chair (เก้าอี้พับเหล็กแบบมวยปล้ำ ฟาดทีลอย แตกได้)
  - 🐟 Giant Fish (ปลายักษ์ เจ็บน้อยแต่ปลิวไกลมาก)
  - 🔺 Traffic Cone (กรวยจราจร ครอบหัวคนโดน)
  - 🍅 Ketchup Bottle (ขวดซอสมะเขือเทศ แตกคาหัว)
- **ของในแมพ**:
  - กระจกหน้าร้านแตกได้ถ้ามีร่างบินเข้าไปชน
  - แตงโมบนแผงผลไม้แตกกระจาย
  - ถังขยะ กล่อง พาเลท กรวย และเก้าอี้รอบเวทีเตะกระจายได้ ถังขยะใหญ่หนัก ร่างที่ลอยมาชนจะเด้ง
  - ศพเตะเล่นได้
- **ฮา**:
  - คำการ์ตูนแบบคอมิกฝรั่งเด้ง เช่น "POW!" "CLANG!!" "SUPLEX!!" "ROCKET PUNCH!!!"
  - ข้อความ KO ฮาๆ เช่น "Big Earl is taking a dirt nap 💤"
  - ฉายาตอนล่าต่อเนื่อง 🔥👹💀
  - รางวัลจบรอบ:
    - 👑 King of the Alley
    - 💪 Heaviest Hitter
    - 🥔 Human Punching Bag
    - 💃 Dance Machine
  - บอทชื่อฝรั่งฮาๆ เช่น "Big Earl", "Granny Gertrude", "Sir Slaps-a-Lot"

## ปรับแต่ง (ไฟล์ `BrawlConfig`)
- `BotCount`, `BotSkill`: จำนวนบอทกับความเก่ง (0 ถึง 1)
- `RoundTime`: ความยาวรอบ
- `MaxHealth`, `WalkSpeed`: เลือดและความเร็ว
- `Blood`:
  - `0` = ไม่มีเลือด (ขึ้นดาวการ์ตูนแทน)
  - `0.5` = น้อย
  - `1` = ปกติ
  - `2` = สาดกระจาย
- `Teeth`, `FaceDamage`: เปิด/ปิดฟันหลุดและหน้าเลือด
- `Moves`: ดาเมจ ระยะ แรงผลัก และเวลาล้มของทุกท่า
- `Weapons`: ค่าของอาวุธแต่ละชิ้น
- `Look`: สีผิว เสื้อ กางเกง ผม และทรงผม
  - ทรงผมที่มี: `box`, `flat`, `spike`, `mohawk`, `bald`, `cap`, `long`, `afro`
- `Words`, `KOMessages`, `BotNames`: ข้อความทั้งหมดในเกม (ภาษาอังกฤษ แก้เป็นภาษาอื่นได้)
- `Sounds`: ตอนนี้ใช้เสียงที่ติดมากับ Roblox ถ้าอยากได้เสียงหมัดเจ๋งๆ ให้เปลี่ยนเป็น `rbxassetid://เลขเสียง` จาก Creator Store

> ⚠️ **ก่อนเปิดเกมสาธารณะ**
> - กฎของ Roblox **ไม่อนุญาตเนื้อหาชำแหละร่างกาย** (แขนขาหลุดแบบเห็นเนื้อและกระดูก หัวหลุด ขาดครึ่งท่อน) ในเกมที่ Publish ให้คนอื่นเล่น
> - ถ้าจะ Publish ให้ตั้ง `GoreLevel = 0` (หลุดแบบบล็อกไม่มีเลือด) หรือ `Dismember = false`
> - เลือดก็ต้องกรอกแบบสอบถาม **Maturity & Compliance** ใน Creator Hub ตามจริง ถ้าอยากให้เด็กเล่นได้ ให้ตั้ง `Blood = 0`
> - ค่าตั้งต้นที่โหดสุดเหมาะสำหรับเล่นทดสอบใน Studio

## โครงสร้างโค้ด
```
Roblox/
  AlleyBrawl.rbxlx         ← ไฟล์ place พร้อมเปิด
  default.project.json     ← สำหรับ Rojo
  tools/build-place.mjs    ← สร้าง .rbxlx ใหม่จาก src/ (รันโค้ดสร้างแมพจริงแล้วบันทึกเป็นชิ้นงาน)
  tools/export.lua         ← ตัวแปลงแมพ/ตัวละครเป็น XML ของ Roblox
  tools/test/              ← ตัวจำลอง Roblox API + ชุดทดสอบ
  src/shared/   BrawlConfig (ค่าทั้งหมด), BrawlAnim (ท่าทาง keyframe)
  src/server/   init.server (รอบ/ผู้เล่น/บอท), MapBuilder (แมพ + ผูกของแตกได้), CharacterBuilder (ร่าง 15 ชิ้น),
                Ragdoll (14 ข้อ + ตัดข้อ), Combat (ต่อสู้ + แขนขาหลุด), Weapons, Bots
  src/client/   init.client, Animator (สปริง+procedural), Effects (เลือด/คำ/เสียง/กล้องสั่น), Hud, Controls
```
- **Server เป็นคนตัดสินการโดนทั้งหมด** (กันโกงเบื้องต้น) แล้วส่งเอฟเฟกต์ไปทุกเครื่อง
- **แอนิเมชันทำในเครื่องผู้เล่น**: ใช้ keyframe ร่วมกับสปริงที่มีการเด้งเล็กน้อย ตัวละครเลยมีน้ำหนัก ไม่แข็งทื่อ
- ตอนตีโดนจะมี hit-stop หยุดภาพแป๊บเดียวให้รู้สึกถึงแรงกระแทก

## การทดสอบที่ทำแล้ว
- ตรวจ syntax และตัวแปร global ทุกไฟล์
- รันโค้ดจริงในตัวจำลอง Roblox API ไม่พบ error:
  - server 130 วินาทีเกม 2 แบบ: แมพสร้างจากโค้ด และแมพกับโมเดลมีอยู่ในไฟล์แล้ว
  - ชุดทดสอบ gore:
    - ตัดขาทีละข้างจนต้องคลาน
    - ตัดแขน มือ หัว และขาดครึ่งท่อน
    - กระทืบศพ
    - ลุกจาก ragdoll ทั้งที่ขาขาด
    - ชิ้นส่วนหายไปเองตามเวลา
  - client ทั้งโหมดคีย์บอร์ดและมือถือ
