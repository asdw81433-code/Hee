# NEON BAY: THE PIT — Roblox Edition

เกมชกมวยแนว Undisputed บน Roblox ในโลกของ Neon Bay (โกดังใต้ดินย่าน Port Marrow ปี 2089)
ใช้ระบบเดียวกับเวอร์ชัน Unity: หมัด 6 แบบ, หลบ/ก้ม/ปัด/การ์ด, สตามินา, ล้มนับ 10, กรรมการ 3 คน, มุมพักระหว่างยก, หน้าบวม-แตก-เลือดออก, ragdoll ตอนน็อก และเชือกเวทีที่ขยับได้จริง

> ทุกอย่างสร้างจากโค้ดและชิ้นส่วนพื้นฐานของ Roblox **ไม่ต้องอัปโหลด asset อะไรเลย** เปิดไฟล์แล้วกด Play ได้ทันที

---

## เปิดเล่น (ไม่ต้องแก้อะไร)

1. ดาวน์โหลดไฟล์ **`NeonBay_ThePit.rbxlx`** (อยู่ในโฟลเดอร์นี้)
2. เปิด **Roblox Studio** → `File` → `Open from File...` → เลือกไฟล์นั้น
3. กด **Play** (F5)
   - ครั้งแรกจะเด้งหน้า **FIGHTER** ให้สร้างนักมวยก่อน (มีพรีวิว 3D หมุนดู และซูมดูหน้าได้)
   - เล่นคนเดียว: กด **CAREER** แล้วกด **FIGHT** เพื่อชกกับ CPU ไต่อันดับ 8 คน จนถึงแชมป์ IRON POLLY
4. ทดสอบหลายคน: แท็บ `Test` → `Clients and Servers` → เลือก 2 Players → `Start`
   แล้วให้แต่ละคนไปยืนบน **วงไฟแดง (RED CORNER)** และ **วงไฟน้ำเงิน (BLUE CORNER)** ข้างเวที นับถอยหลัง 5 วินาทีแล้วขึ้นชกกันเอง

### เอาขึ้น Roblox จริง
- `File` → `Publish to Roblox`
- ถ้าอยากให้บันทึกสถิติ/เงิน/หน้าตา: `Game Settings` → `Security` → เปิด **Enable Studio Access to API Services** (ตอนเผยแพร่จริงจะบันทึกด้วย DataStore อัตโนมัติ ถ้าไม่เปิดเกมก็ยังเล่นได้ แค่ไม่จำข้อมูลข้ามรอบ)

## มีอะไรในเกม

**การชก (คำนวณฝั่งเซิร์ฟเวอร์ทั้งหมด กันโกง)**
- หมัด 6 แบบ ชกหัวหรือลำตัว, หมัดหนัก, คอมโบสลับมือได้เร็วขึ้น, หมัดสวน (counter) แรงกว่า
- ป้องกัน: การ์ด, ปัดหมัด, เบี่ยง, ก้ม, เอนหลบ — ก้มเข้าหาอัปเปอร์คัตหรือเบี่ยงเข้าหาฮุกจะโดนหนักกว่า
- สตามินา + ความล้าสะสม (ชกวืดเสียแรงมาก), ความเสียหายที่หัว/ลำตัว, อาการมึน (ROCKED), ลิเวอร์ช็อตล้มช้า, กอดรัด
- ล้ม: กรรมการนับ 1–10, มินิเกมลุก, ล้ม 3 ครั้งในยก = TKO, หมอสั่งยุติเมื่อแผลแตกหนักหรือตาปิด
- กรรมการ 3 คน ให้คะแนน 10-point must แต่ละคนเน้นต่างกัน (ตัดสินเอกฉันท์ / เสียงข้างมาก / แบ่ง / เสมอ)
- ช่วงพักมุม: เลือก ห้ามเลือด / ประคบตา / พักหายใจ / บุกเอาน็อก + โค้ชให้คำแนะนำตามสถิติจริง
- CPU 8 คน 5 สไตล์ (Out-Boxer, Swarmer, Slugger, Counter-Puncher, Brawler) อ่านหมัดด้วยเวลาตอบสนองแบบคน

**ตัวละคร**
- สร้างกายวิภาคด้วยมัดกล้าม: อก, ซิกแพ็ก, ปีก, บ่า, ไหล่, ไบเซ็ป, ต้นขา, น่อง
- ทรงผม 14 แบบ (เดรดล็อก/หางม้า/ผมยาวแกว่งตามแรงเหวี่ยง), หนวดเครา 10 แบบ, คิ้ว 5 แบบ, สีผม/สีเครา, รูปกราม, ส่วนสูง, หุ่น, กล้าม, กางเกง/นวม, ท่ายืน orthodox/southpaw, รอยสักนีออน
- **หน้ามีชีวิต**: ตามองคู่ชก, กะพริบตา, คิ้ว, ขากรรไกรอ้าตอนโดนหมัด, หัวสะบัดตามทิศหมัด, หายใจหอบเมื่อเหนื่อย, ตาเหลือกตอนน็อก
- **บาดเจ็บสมจริง**: ตาบวมจนปิด (ภาพฝั่งนั้นมืดลงจริง), โหนกแก้มบวมช้ำ, จมูกบวมเลือดไหล, คิ้วแตกเลือดไหลเป็นทาง, เลือดหยดลงพื้นเวทีเป็นคราบ, เหงื่อกระเซ็นตอนโดนหมัด, ผิวเป็นเงาเหงื่อเมื่อเหนื่อย, บาดแผลติดตัวข้ามไฟต์ (รักษาที่ MEDICAL)
- **Ragdoll** ตอนน็อก: ข้อต่อแบบลูกบอลและบานพับตามกายวิภาค (เข่า/ศอกงอทางเดียว) พร้อมแรงส่งจากหมัด

**ฉาก / ลูกเล่น**
- เวที 2 เวที (เวทีหลัก + เวทีซ้อม), **เชือก 4 เส้นต่อด้าน จำลองฟิสิกส์ verlet** ยุบ-เด้ง-สั่นเมื่อคนพิง/ล้มใส่
- ไฟเวทีเงาจริง (Future lighting), ป้ายนีออน, บาร์, กระสอบทรายแกว่งได้จริง, ไอน้ำ, ถังไฟ, ฝนนอกหน้าต่าง, ตึกเมือง Neon Bay
- กล้องถ่ายทอดสด: ข้ามไหล่, มุมข้างเวที (B), มุมล้ม, หมุนรอบตอนน็อก, ซูมหน้าตอนพักมุม (เห็นแผลชัด), ช็อตผู้ชนะ
- กล้องสั่นแบบ trauma, กระตุกตามทิศหมัด, FOV punch, จอแดงแวบ, เบลอ/โคลงเคลงตอนมึน
- ผู้ชมรอบเวทีกระโดด ชูกำปั้น ปรบมือตามจังหวะไฟต์

## โครงสร้างไฟล์

| โฟลเดอร์ | อยู่ที่ไหนใน Roblox | หน้าที่ |
|---|---|---|
| `src/shared` | ReplicatedStorage.NeonBay | ค่าตั้ง (Config), ตารางหมัด, โครงกระดูก, สร้างหน้าตา/ผม/เครา, คณิต IK |
| `src/server` | ServerScriptService.NeonBay | สร้างตัวละคร, นักมวย, แมตช์, AI, ragdoll, บันทึกข้อมูล |
| `src/client` | StarterPlayerScripts.NeonBay | แอนิเมชันทั้งหมด (Motor6D + IK), กล้อง, ปุ่ม, HUD, เมนู, เชือก, ผู้ชม, เอฟเฟกต์ |
| `build/build_place.luau` | — | สคริปต์สร้างแมพ + รวมโค้ดเป็น `NeonBay_ThePit.rbxlx` |
| `tests/` | — | ทดสอบรันโค้ดจริงแบบไม่มีหน้าจอ (สร้างตัวละครทุกแบบ + จำลองไฟต์เต็มรูปแบบ) |

**อยากแก้ค่าเกม** เช่น ความยาวยก, ความแรงหมัด, เสียง: แก้ใน `src/shared/Config.luau` (หรือใน Studio ที่ `ReplicatedStorage > NeonBay > Config`)

**เสียง**: ค่าเริ่มต้นใช้เสียงที่ติดมากับ Roblox เพื่อให้เปิดเล่นได้ทันที ถ้ามีเสียงของตัวเอง (หรือหาใน Creator Store) ให้วาง `rbxassetid://...` แทนใน `Config.Sounds` ช่อง `crowd` เว้นว่างไว้ให้ใส่เสียงผู้ชม

### สร้างไฟล์ใหม่จากซอร์ส (สำหรับนักพัฒนา)
```bash
# ต้องมี lune (cargo install lune) / rojo (cargo install rojo)
lune run build/build_place.luau          # สร้าง NeonBay_ThePit.rbxlx + build/Map.rbxmx
rojo serve                               # หรือซิงก์โค้ดเข้า Studio สดๆ ด้วย Rojo
lune run tests/test_rigs.luau            # สร้างนักมวยทุกทรงผม×เครา (140 แบบ)
lune run tests/test_fight.luau           # จำลองไฟต์ 8 คู่ด้วยโค้ดเซิร์ฟเวอร์จริง
```

## สิ่งที่ควรรู้ (ตรงไปตรงมา)
- ผมสร้างและตรวจโค้ดนี้ในเครื่องที่ไม่มี Roblox Studio จึง **ยังไม่ได้กด Play ใน Studio จริง** สิ่งที่ตรวจแล้ว: คอมไพล์ Luau ผ่านทุกไฟล์, lint ไม่มีตัวแปรที่ไม่ได้ประกาศ, ทุก class/enum/property/method ตรงกับ API definitions ของ Roblox, รันโค้ดสร้างตัวละครจริงครบ 140 แบบ และจำลองไฟต์เต็มรูปแบบด้วยโค้ดเซิร์ฟเวอร์จริง 8 แมตช์จนจบ (KO / TKO / ตัดสินคะแนน)
- ถ้าเจอข้อความแดงใน Output ของ Studio ให้ส่งข้อความนั้นมา จะแก้ให้ต่อ
- แอนิเมชันทั้งหมดเป็นแบบ procedural (คำนวณสด) ไม่ได้ใช้ไฟล์ Animation จึงไม่ต้องอัปโหลดอะไร แต่ถ้าอยากได้ท่าที่ละเอียดกว่านี้ สามารถทำ Animation ใน Studio มาเสริมทีหลังได้
